# 比赛地图、开局与终局规则

同步日期：2026-09-27。供主代理和隔离作者共同阅读；机器摘要见 [rules.json](rules.json)。这是比赛条件，不是参数答案，也不改变固定实现或替作者决定战术。

## 适用范围与官方开局

已确认的赛事规则覆盖 1v1、2v2、4v4、ffa8。FFA8 是八名独立玩家；团队模式分别为两队两人、两队四人。网页另外支持的 3v3、ffa4 尚无这份赛事规则的授权记录，不能自动套用。

基础玩法是《帝国时代 II：决定版》标准随机地图（Standard Random Map）体系；不是官方 Battle Royale，也不是帝国战争（Empire Wars）。QS（Quick Start）是官方快速开局**地图变体**，官方说明为比普通开局多六名村民。不要把它理解成直接封建开局，也不要固定按普通三村开局设计。

一般按黑暗时代开局理解，但实际资源、村民数、已有建筑、人口上限、游戏速度、胜利条件及地图大小必须以本轮房间/场景清单为准。QS Nomad 不能假定已经有城镇中心；文明与场景也可能调整初始条件。

承载自定义终局规则时，游戏大厅实际选择的是**自定义场景**。这是把随机地图开局加上赛事裁判逻辑，不是把官方游戏模式改叫“突然死亡”。只选官方 QS 随机地图不会自动获得下面的 60/90/120 分钟规则；AI 的 PER 也不负责自行给全场加伤害、禁建、开视野或判负。

## 60、90、120 分钟分别发生什么

全部按**游戏内时钟**，不是现实等待时间；暂停时不推进。60/90/120 分钟对应 3600/5400/7200 游戏秒。

| 时间 | 主办方赛事规则 |
| --- | --- |
| 0—60 分钟 | 正常发展、升代、战斗；没有提前禁建或提前百死淘汰。 |
| 60 分钟 | 第一档破城加成 ×2。该称呼指赛事定义的对建筑伤害加成，不能解释为所有攻击、采集或生产速度翻倍。具体适用单位/伤害项须以场景实现为准。 |
| 90 分钟 | 第二档破城加成累计 ×4（不是再乘四变 ×8）；禁止新建建筑、农田及补种，已有地基允许完工；开启阶段全视野与突然死亡计数。 |
| 90—120 分钟 | 只算90分钟以后新增的单位死亡，达到100即淘汰。1v1/FFA按个人，2v2/4v4按全队合计；不计建筑，不用杀敌或拆建筑抵消死亡。淘汰方单位和建筑清除，退出后续统计。 |
| 120 分钟 | 对仍未淘汰者，先按90分钟后新增单位死亡**少者优先**；死亡相同，再按同期新增敌方单位击杀**多者优先**。团队均全队合计，建筑和90分钟前历史值不计。 |

自然征服可以提前结束；FFA提前只剩两家，也不会提前开启90分钟阶段。死亡与击杀完全同分，以及多方同时百死、导致无人存活的最终裁定仍未定，不能私自抽签或宣布唯一冠军。FFA候选场景的完全并列处理是冻结规则计数并提示主办方裁定，不代表已有自动决胜规则。

对作者的实际含义：开局根据真实村民和资源安排采集、生产和升代；升代不要被可反复跌落的人口门槛永久锁住。设计60分钟后的破城能力、90分钟前的必要基础设施，以及90分钟后的部队保存和损失控制。具体打法、兵种、升代时间仍由作者决定。不要根据尚未证实的全视野提前读取隐藏敌情，也不要把这些规则伪装成已实装的 PER 能力。

## 已实现到哪一步

- **规则确认**：四模式已确认以上框架；完全同分/同时淘汰的最终处理待定。
- **FFA8候选场景**：2026-09-18 的 `FFA8_QS_ARABIA_ENDGAME.aoe2scenario` 已生成并安装；记录显示文件回读、XS语法和安装哈希通过，完整新版实机效果仍为 `Unverified`。这不是2026-09-27重新验证安装的结果。
- **该场景的特定开局快照**：八家各9村民，木170、食110、金100、石200；这只是该候选场景的数据，不是七图/所有文明的官方通用初始资源。
- **其他地图及团队模式**：纳入规则不代表运行适配完成；不能宣称已有七图四模式完整执行器。
- **计数边界**：原生死亡计数对自删等特殊死亡的覆盖、完整联动仍需游戏验证。不能把离线检查当实机通过。
- Skill 只提供资料；不随这次同步安装场景，也不修改游戏。每场主办方应冻结实际地图/场景版本与哈希、种子、房间设置、规则版本和执行状态。未提供时保持未知。
