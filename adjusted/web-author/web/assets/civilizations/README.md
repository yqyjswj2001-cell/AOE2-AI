# 文明盾徽素材

本目录固定保存标准版 42 个文明的原始 PNG、`manifest.json` 来源清单与本说明。
图标取自用户指定的 AoE2 AI Studio：`tools/author_agent/assets/civ-shields/`，保持 104 × 104 原始画布和文件字节，不裁切、不重绘。

- 当前范围以 `../../../standard-edition.json` 的 42 文明白名单为准。
- 文件名使用资料内部 ID；`Indians.png` 对应印度斯坦（Hindustanis）。
- 页面资源地址为 `/assets/civilizations/<内部ID>.png`。
- `manifest.json` 记录每张图的原始 SHA-256、尺寸和上游路径。
- 资料由 `../../../civilization_catalog.py` 从冻结事实读取；图片不提供或覆盖文明数值。

素材原始来源：[SiegeEngineers/aoe2techtree](https://github.com/SiegeEngineers/aoe2techtree/tree/b9d494df6921d4080df69b22f9dbb7a4d1dcd9f0/img/Civs)，沿用 Studio 清单记录的提交版本。
