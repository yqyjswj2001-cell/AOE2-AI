# 参数归属

现有 2295 个候选参数全部完成静态分类：1715 个保留动态，580 个恢复官方固定值。

- 固定代码与参数使用官方原文，不提供给策略作者，也不允许填写或重写。
- 动态项必须列入 [完整分类表](cloze/classification/README.md)；仅出现占位符不再足以证明它应当动态。
- 模板必须与分类表的来源哈希和逐个数字位置一致；未列明的地方全部固定。
- 作者只拿 [策略说明卡](cloze/strategy/README.md)、全 null 答卷和基础游戏事实，不拿完整 PER、官方答案或分类表。
- 主代理机械替换答案、校验关系；不翻译策略、不补写固定代码、不自动修正作者选择。
- 官方原值回填必须逐字节还原原件。静态正确与游戏表现分别取证。
