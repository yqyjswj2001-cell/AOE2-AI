# Parameter Ownership

There is only one ownership rule.

## Fixed

Everything copied from `official/raw/Promisory/` that is **not** replaced by a
`{{PLACEHOLDER}}` is fixed.

Fixed content is not re-designed, reinterpreted, or regenerated by the strategy
AI. It stays exactly as the official script wrote it.

## Dynamic

Only explicit `{{PLACEHOLDER}}` values inside
`adjusted/cloze/Promisory/*.per.tpl` are dynamic.

The strategy AI may fill those values, and nothing else.

## Proof

For every cloze template, the repository stores the original official values in
`adjusted/cloze/official-defaults/`.

Filling the template with those values must reconstruct the corresponding
official `.per` file byte-for-byte. CI rejects the change otherwise.
